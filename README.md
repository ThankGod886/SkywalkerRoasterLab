# SkywalkerRoasterLab
Ⅰ<br>
這是我修改的程式，讓 Skywalker Roaster 能夠使用USB線連接到 Artisan 和 無線藍芽連接到HiBean。它使用 ESP32-S3-DevKitC-1 作為控制器。<br>
[Skywalker Coffee Roaster 雙用控制器Artisan及HiBean 製作](https://skywalkercoffeeroaster.blogspot.com/2025/04/blog-post.html)<br>
This is my modified program that allows the Skywalker Roaster to connect to Artisan via USB cable and to HiBean via Bluetooth. It uses the ESP32-S3-DevKitC-1 as the controller.<br>
[Skywalker Coffee Roaster Dual-Use Controller by Artisan and HiBean](https://skywalkercoffeeroaster.blogspot.com/2025/04/blog-post.html)<br>

ⅠⅠⅠ<br>
Develop a Modbus device using an Arduino Uno or Nano and a MAX6675 (KType) or MAX31865 (RTD). Connect it to a computer via USB to add a second temperature probe to the Skywalker. In Artisan, simply add an extra device to use it. The original ESP32 S3 controller can run simultaneously without any changes.
